# Запуск бота 24/7

## Анти-бот стратегія

Бот розроблено щоб **уникнути блокування** навіть під час 24/7 роботи:

### Частота запитів
```
- Перевіряє кожне місто кожні 300 секунд (5 хвилин)
- = 288 перевірок/день на одне місто
- + 30-90s випадкова затримка (jitter) — уникає передбачуваних патернів
```

### Anti-bot тактики
✅ **User-Agent rotation** — змінює браузер на кожен запит  
✅ **Затримки між городами** — 1-3s між перевіреннями  
✅ **Exponential backoff** — при ошибках чекає все довше  
✅ **Headless Playwright** — справжній браузер, не бот-library  
✅ **Cloudflare bypass** — автоматичний клік на Cloudflare чек  

### Результат
🎯 Бот перевіряє доступність регулярно але виглядає як нормальний користувач з непередбачуваною поведінкою.

## Запуск на Windows

### Варіант 1: Command Prompt (просто)
```bash
python bot.py
```
Залишити вікно відкритим. Бот буде крутитися та виводити лог.

### Варіант 2: Task Scheduler (автоматично при запуску ПК)

1. Відкрити **Task Scheduler**
2. Клацнути "Create Basic Task"
3. Назва: "Queue Bot"
4. Тригер: "At startup"
5. Дія: Program/script
   ```
   C:\Python311\python.exe
   ```
6. Аргументи:
   ```
   C:\Users\facet\Downloads\Videos\bot.py
   ```
7. Галочка "Run whether user is logged in or not"

### Варіант 3: Screen/Tmux сесія (якщо є WSL)
```bash
# Запустити в тлі
screen -S queue-bot -d -m python bot.py

# Подивитись лог
screen -S queue-bot -r

# Вийти з сесії
Ctrl+A потім D
```

## Запуск на Linux/VPS

### Systemd сервіс (рекомендо)

Створити `/etc/systemd/system/queue-bot.service`:
```ini
[Unit]
Description=Telegram Queue Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/queue-bot
ExecStart=/usr/bin/python3 bot.py
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

Активувати:
```bash
sudo systemctl daemon-reload
sudo systemctl enable queue-bot
sudo systemctl start queue-bot
sudo systemctl status queue-bot
```

Логи:
```bash
sudo journalctl -u queue-bot -f
```

## Налаштування

### `.env` файл

| Параметр | Значення | Приклад |
|----------|----------|---------|
| `BOT_TOKEN` | Твій Telegram бот токен | `123456:ABC...` |
| `MODE` | `demo` або `live` | `live` |
| `CHECK_INTERVAL` | Секунди між перевіреннями | `300` (5 хвилин) |
| `ADMIN_ID` | Твій Telegram ID для помилок | `123456789` |

### Оптимизація для твоєї сітки

Якщо черга часто відкривається:
```env
CHECK_INTERVAL=180  # 3 хвилини (480 перевірок/день)
```

Якщо черга рідко відкривається:
```env
CHECK_INTERVAL=600  # 10 хвилин (144 перевірок/день)
```

Рекомендована: **300 секунд (5 хвилин)**

## Проблеми & Рішення

| Проблема | Рішення |
|----------|---------|
| "429 Too Many Requests" | Збільш `CHECK_INTERVAL` на 600+ |
| "Cloudflare detected" | Бот намагається обійти автоматично |
| Немає дат хоча черга відкрита | Селектор сторінки змінився, розповідай мені |
| Бот повно логує | Змінюєш рівень логування на INFO (не DEBUG) |

## Як перевірити що працює

1. Запустити бота:
   ```bash
   python bot.py
   ```

2. Написати в Telegram:
   ```
   /start
   /subscribe
   ```

3. Вибрати місто та послугу

4. Бот почне перевіряти та писати:
   ```
   checked: 0 open dates
   checked: 0 open dates
   ```

5. Коли черга відкриється → отримаєш повідомлення:
   ```
   🟢 Відкрилась черга!
   📍 Варшава
   📄 Закордонний паспорт
   
   Вільні дати:
   • 20.11.2026
   • 21.11.2026
   ```
