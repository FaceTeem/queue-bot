# Бот сповіщень про талони ДП «Документ»

Бот перевіряє вільні талони раз на кілька хвилин і пише підписникам у Telegram. Записується людина сама на офіційному сайті.

## 1. Встановлення (Windows / macOS / Linux)

Потрібен Python 3.10+.

```
cd queue_bot
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS / Linux
pip install -r requirements.txt
```

## 2. Створіть бота в Telegram

1. Напишіть @BotFather → `/newbot` → отримайте токен.
2. Дізнайтесь свій Telegram ID (наприклад, через @userinfobot).
3. Скопіюйте `.env.example` у `.env` і впишіть `BOT_TOKEN` та `ADMIN_ID`.

## 3. Тест у демо-режимі

У `.env` залиште `MODE=demo`, поставте `CHECK_INTERVAL=30` і запустіть:

```
python bot.py
```

Напишіть боту `/subscribe`, оберіть місто — за хвилину-дві прийдуть тестові сповіщення.

## 4. Підключення до справжніх даних

1. Відкрийте сайт Паспортного сервісу в Chrome і увійдіть через Дія.Підпис або BankID.
2. Натисніть F12 → вкладка **Network** → фільтр **Fetch/XHR**.
3. Відкрийте сторінку вибору міста/дати для запису. Шукайте запит, у відповіді (**Response**) якого є список вільних дат (календар). Час не потрібен.
4. Скопіюйте його URL у `SLOTS_URL`.
5. У **Headers → Request Headers** скопіюйте значення `Cookie` у `SESSION_COOKIE` (і `Authorization`, якщо є, у `AUTH_HEADER`).
6. Перепишіть `parse_response()` у `fetcher.py` під структуру цієї відповіді.
7. Поставте `MODE=live` і перезапустіть.

Сесія з часом закінчується — бот напише адміну, і треба буде знову скопіювати свіжий Cookie.

> Cookie = доступ до вашого акаунта. Нікому не передавайте `.env` і не викладайте його в GitHub.

## Правила, щоб не отримати блок

- Не ставте інтервал менше 2 хвилин: частіші запити навантажують сайт і можуть призвести до блокування акаунта.
- Бот лише сповіщає. Не додавайте автоматичне бронювання — це порушує правила сервісу й шкодить людям у черзі.
- Перевірте умови використання сайту перед запуском для широкої аудиторії.

## Команди бота

- `/subscribe` — підписка на місто й послугу
- `/my` — мої підписки
- `/stop` — відписатися від усього
