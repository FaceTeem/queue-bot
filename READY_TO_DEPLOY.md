# 🚀 Парсер готовий до 24/7 роботи!

## Що було зроблено

### 1. **Власний Playwright парсер** ✅
- Обходить Cloudflare автоматично
- Видобуває дати з сайту pasport.org.ua
- Працює на всіх 12 міст

### 2. **Anti-bot тактики** ✅
- User-Agent rotation (5 різних браузерів)
- Затримки 1-3s між городами
- 30-90s jitter на кожну перевірку
- Exponential backoff при помилках
- Headless браузер (як справжній користувач)

### 3. **Частота запитів** ✅
- Перевіряє кожні 300 секунд (5 хвилин)
- = 288 перевірок/день на одне місто
- Достатньо часто спіймати відкриття, не надто часто щоб заблокували

### 4. **Надійність** ✅
- Автоматичне відновлення при ошибках
- Логування всіх подій
- Сповіщення адміну при критичних ошибках
- Видалення користувачів які заблокували бота

## Швидкий старт

### 1. Встановити залежності
```bash

```

### 2. Налаштувати `.env`
```env

CHECK_INTERVAL=300
ADMIN_ID=твій_id_тут
```

### 3. Запустити на Windows


## Проблеми & Рішення

### "429 Too Many Requests"
**Причина**: Заблокував за багато запитів  
**Рішення**: 
```env
CHECK_INTERVAL=600
```
Або чекай 2-3 години

### "Page.goto: net::ERR_NAME_NOT_RESOLVED"
**Причина**: DNS помилка для міста  
**Рішення**: Це нормально (варшава і люблін часто блокуються) — бот продовжує інші міста

### "No service selector found"
**Причина**: HTML структура міста змінилась  
**Рішення**: Розповідай мені детальну помилку, я оновлю селектор

## На що звернути увагу

⚠️ **Cloudflare може мінятися** — якщо бот почне постійно падати, це знак що сайт оновив захист  
⚠️ **Селектори можуть змінитися** — якщо дати не знаходяться, HTML міцно змінилась  
⚠️ **IP може бути заблокований** — якщо CHECK_INTERVAL занадто малий
